# Road to 0.70+ SOTA Implementation Plan: "Name That LLM"

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Elevate the Kaggle "Name That LLM" solution from the current baseline (0.355 LB / 0.394 CV) to 0.50+ on the immediate next run, and scale systematically to 0.70+ via dual-trunk representations, contrastive prompt-cluster fine-tuning, ANOVA quotient space projection, and iterative Sinkhorn-Knopp marginal calibration.

**Architecture:**
1. Dual representation extraction from foundation LLM backbones (`Qwen3-8B-Base` and `allenai/OLMo-2-1124-7B`) reading early-to-mid layers (layers 8–20) with `concat(mean, max)` pooling.
2. Orthogonal handcrafted dense stylometry (74 typographic, clausal, and em-dash spacing geometry features).
3. Crossed Two-Way ANOVA topic-annihilation ($\tilde{\mathbf{Z}} = \mathbf{Z} - \bar{\mathbf{Z}}_{\text{prompt}} + \bar{\mathbf{Z}}$) projecting into a 17-dimensional canonical author quotient space via Generalized Eigenvalue Decomposition ($S_b \mathbf{v} = \lambda S_w \mathbf{v}$).
4. Two-stage LoRA fine-tuning with hard contrastive prompt-cluster batches (anchor model $m$ on prompt $p$, negative models on same prompt $p$).
5. Test-time soft cavity EM with mutual class repulsion and 100-iteration Sinkhorn-Knopp marginal balancing.

**Tech Stack:** PyTorch 2.6, Hugging Face Transformers, PEFT, Scikit-learn, Scipy, LightGBM, KaggleHub, Dual Nvidia Tesla T4 (2x16 GB = 32 GB VRAM).

## Global Constraints
- **Strictly Remote Execution**: No local model training or heavy inference. Local machine is strictly for code authoring, linting, packaging, and dispatch. All heavy compute runs on Kaggle Dual T4.
- **Metric Invariant**: Submissions are evaluated strictly on unweighted Balanced Accuracy ($\frac{1}{18} \sum_{k=1}^{18} \text{recall}_k$). Baseline random guess is $0.0556$.
- **Validation Invariant**: All CV evaluation MUST use `StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42)` grouped strictly on `prompt_id` with `ClusterDropout` simulation to prevent optimistic prompt leakage.
- **Offline Rerun Invariant**: Final submission notebook must execute in $\le 9$ hours without internet access on ~4,000 hidden test rows producing `/kaggle/working/submission.parquet`.
- **Telemetry Invariant**: Always import and use `tqdm` (`from tqdm.auto import tqdm`) across all batch loops and feature extraction runs.

## Review Focus
1. **GLM vs. Claude Typographic Collision**: Both models emit straight quotes and high em-dash rates; unspaced em-dashes (`"—"`) identify Claude while spaced em-dashes (`" — "`) identify GLM.
2. **Gemini Flash 3-Way Sibling Collision**: `gemini-3.6-flash`, `3.7-flash`, and `3.8-flash` share near-zero em dashes; curly apostrophe rates (6% vs 31%) and sentence length CV separate them.
3. **OpenAI 5-Sibling Variance**: Reasoning variant `gpt-5.6-sol` exhibits distinct discourse transition markers compared to grounded `gpt-5.6-terra`.
4. **Ragged Test-Cluster Prior Shift**: Test set contains varying prompt cluster sizes (2 to 18); hard assignment (Hungarian) collapses, requiring soft cavity EM with mutual repulsion.
5. **Class Recall Floor**: A global score increase accompanied by a collapse on minority classes (e.g. `glm-5.3` recall < 0.10) directly punishes Balanced Accuracy; min-class recall must remain $\ge 0.35$.

    # Assert column sums are balanced (N / K)
    expected_col_sum = N / K
    assert np.allclose(P_balanced.sum(axis=0), expected_col_sum, atol=1e-2)
